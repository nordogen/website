# NORDOGEN

Bilingual (Serbian / English) marketing website for NORDOGEN d.o.o., a Serbian company
producing food supplements for urology, gynaecology and regeneration.

Informational only — no e-commerce, accounts or forms. Content is edited through a built-in
CMS that commits to this repository.

Next.js · Tailwind CSS · Keystatic · deployed on Vercel.
